
## 1. Definición de VLAN
Una **VLAN (Virtual Local Area Network)** es una red lógica independiente que se crea dentro de un switch físico.  
Permite segmentar el tráfico de red a nivel de capa 2 (capa de enlace de datos), brindando:
- **Separación de broadcast**: cada VLAN es su propio dominio de broadcast.
- **Mejora de seguridad**: usuarios en diferentes VLAN no se comunican sin un dispositivo de capa 3.
- **Flexibilidad y administración**: agrupa dispositivos por función, no por ubicación física.

---

## 2. Tipos de VLAN

| Tipo | Descripción |
|------|------------|
| **VLAN de datos** | Transporta el tráfico de usuario (por ejemplo, VLAN 10 para el departamento de Ventas). |
| **VLAN nativa** | Tráfico sin etiquetar en enlaces troncales (por defecto VLAN 1, pero se recomienda cambiarla). |
| **VLAN de administración** | Permite la gestión remota del switch (normalmente separada del tráfico de datos). |
| **VLAN de voz** | Optimizada para tráfico VoIP, con QoS y etiquetado especial. |
| **VLAN predeterminada** | VLAN 1: todos los puertos están en ella por defecto hasta ser reconfigurados. |

---

## 3. Componentes Clave

- **Access Port**: Puerto que pertenece a una sola VLAN y lleva tráfico **no etiquetado**.
- **Trunk Port**: Puerto que transporta varias VLANs y usa **802.1Q** para etiquetar el tráfico.
- **VLAN ID**: Número que identifica la VLAN (rango normal: 1–1005, extendido: 1006–4094).

---

## 4. VLAN Interface (SVI o VLANIF)
Para que una VLAN pueda comunicarse con otras redes o se pueda gestionar el switch, se configura una **interfaz lógica de capa 3** llamada:
- **SVI (Switched Virtual Interface)** en Cisco IOS.
- **VLANIF** en otros fabricantes.

### Ejemplo de configuración SVI en un switch L3:
```bash
Switch(config)# interface vlan 10
Switch(config-if)# ip address 192.168.10.1 255.255.255.0
Switch(config-if)# no shutdown
```
>Esta interfaz actúa como puerta de enlace para los hosts en la VLAN 10.


## 5. Configuración Básica de VLAN en Cisco IOS

### 5.1 Crear VLAN

```
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name Ventas
Switch(config-vlan)# exit
```

### 5.2 Asignar un puerto a la VLAN

```
Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
```

### 5.3 Configurar un enlace troncal

```
Switch(config)# interface gigabitEthernet 0/1
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30
```

## 6. Comunicación entre VLANs (Inter-VLAN Routing)

Las VLANs **no se comunican entre sí** sin un dispositivo de capa 3.

Opciones:

- **Router-on-a-stick**: un router con subinterfaces 802.1Q.
    
- **Switch Layer 3**: SVI con routing habilitado.

 **Ejemplo Router-on-a-stick**

```
Router(config)# interface g0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
```

## 7. Buenas Prácticas

- Cambiar la VLAN nativa por otra diferente a la 1.
    
- Mantener una VLAN de administración separada y segura.
    
- Deshabilitar puertos no usados y asignarlos a una VLAN “inactiva”.
    
- Documentar cada VLAN: nombre, ID, rango de IP, propósito.


## 8. Comandos de Verificación

|Comando|Función|
|---|---|
|`show vlan brief`|Lista VLANs y puertos asignados.|
|`show interfaces trunk`|Verifica puertos troncales y VLANs permitidas.|
|`show running-config`|Muestra configuración activa.|
|`ping`|Prueba de conectividad entre VLANs (si existe routing).|
